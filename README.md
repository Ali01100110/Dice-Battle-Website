# 🎲 Dice Battle Website

A dynamic, interactive web-based dice game where players can face off or test their luck. Built with standard web technologies, this project features responsive design, smooth UI transitions, and game logic rules tailored for an engaging dice battle experience.

## 🚀 Live Demo

👉 [Live Project Link](https://ali01100110.github.io/Dice-Battle-Website/)

---

## ✨ Features

- **Interactive Gameplay:** Instant dice-rolling mechanics with random outcome generation.
- **Score & State Tracking:** Automatically calculates and displays the winner based on the rolled values.
- **Responsive Web Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Modern UI/UX:** Clean aesthetics, visually distinct dice representations, and intuitive controls.

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for the gameplay interface.
- **CSS3:** Modern styling, layout controls (Flexbox/Grid), and interactive animations.
- **JavaScript (ES6+):** Game logic control, state manipulation, and dynamic DOM updates.

## ⚙️ Installation & Local Setup

To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**

```bash
git clone https://github.com/Ali01100110/Dice-Battle-Website.git

```

2. **Navigate into the project directory:**

```bash
cd Dice-Battle-Website

```

3. **Open the project:**
   Simply double-click the `index.html` file to run it directly in your browser, or open the folder in an editor like **VS Code** and use the **Live Server** extension.

---

## 🎮 How to Play

1. Open the website on your browser.
2. Click the **"Roll"** or **"Play"** button to trigger the battle.
3. The script randomly generates two numbers between 1 and 6 for the respective sides.
4. The screen instantly announces the winner (or a draw) based on the higher number rolled!
